## 这次对攻击闪回的处理

上一版关注了回合末解除极巨化，但没有覆盖“每次攻击期间几帧闪回”。

代码中一个确定的间隙是：物理攻击 CSS 动画长 650ms，动画类在 680ms 移除；CSS 动画没有 forwards 填充，原来的图片基础样式又没有永久 transform，因此动画结束后约 30ms 会丢失写在关键帧里的缩放与翻转。特殊攻击和受击也需要防止同类耦合。

本次：
1. 永久形态缩放移到独立的 CSS `scale` 属性。
2. 攻击、受击、待机等关键帧只负责相对运动和瞬时表现，不再承担永久体型。
3. 基础 transform 保留精灵朝向，动画结束间隙不再回到无翻转的默认值。
4. 保留上一版的最后一回合延迟解除和图片节点复用修复。
5. 更新入口、资源缓存参数、桥接版本及应用握手版本为 v1.3.11。

不是通过延长动画或遮挡精灵来隐藏闪回，也没有改招式伤害和极巨化回合规则。

## 安装

1. 备份旧网站、角色卡和聊天。
2. 解压 `pokemon-battle-v1.3.11-完整网站包.zip`，将 `pokemon-battle/` **里面的内容**覆盖到原仓库根目录。根目录应直接有 `index.html`、`preview.html`、`src/`、`st-bridge/`。
3. 保留你自己录制的叫声、图片等附加资源，不要删除它们。
4. 提交并等待 GitHub Pages 部署完成。
5. 打开对战首页，确认页脚 v1.3.11；顶部有「天气 / 场地预览」入口。
6. 导入配套 v1.3.11 角色卡，或将旧卡桥接脚本加载地址改为 `bridge.js?v=1.3.11`。关闭旧战斗窗口并刷新酒馆。
7. 新版酒馆对战弹窗也增加了「效果预览」链接，新开页面预览，不影响当前对战。

不要只替换 styles.css：本次精灵动画、环境脚本、背景素材、预览页及版本缓存需一起更新。

## 本机运行 / 复测

```bash
cd pokemon-battle
python3 -m http.server 8000
# 浏览器打开 http://localhost:8000/preview.html

npm test
# 浏览器测试另需 Playwright + Chromium，静态服务保持运行
node tests/preview-regression.mjs
node tests/visual-environment.mjs
node tests/visual-environment.mjs --gmax
```

不要直接双击 HTML：页面要从同一个静态服务器加载数据与脚本。网页代码没有写死 localhost 服务地址。

完整包是本地修改，不包含远程推送；相对原仓库的 patch 是可选开发者文件，不需要和完整网站包重复安装。
