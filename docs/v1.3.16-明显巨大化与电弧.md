# v1.3.16｜明显巨大化与增强电弧

## 为什么之前不明显

原来喷火龙等大体型的极巨化体型系数接近普通形态，主要只有 1.18 倍永久缩放；较小的宝可梦差异较大，但喷火龙等看不出巨大化。旧电弧约 1 像素粗、持续约 0.65 秒，淡黄色与底板对比不足，出现间隔也长。

## 按你选择的“明显变大，尽量完整显示”调整

- 同时增加巨大形态的布局体型和独立永久缩放，不靠短暂变身动画假装变大。
- 超极巨化使用额外尺寸档位；根据场地宽高自动限制尺寸并平移，不以故意大面积出框表现张力。
- 同步校正阴影与光晕的脚下位置；敌方巨大形态也调整站位以留出空间。
- 超极巨化增加成长过程、头顶云层与一次落地扩散，避免以持续频闪表现张力。
- 电弧更长、更粗，增加深色边缘和浅色内芯，显示时间约 1 秒；自动出现仍有间歇，不是铺满画面的爆闪。
- 连续场地、风吹草叶、阴雨雷光、沙尘滤镜和无背景图设定均保留。

## 先在自由预览比较

打开当前会话「明显巨大化与增强电弧预览 v1.3.16」。

1. 选择喷火龙，依次点普通、极巨化、超极巨。
2. 点新增的「重播巨大化」，观察成长、超极巨云层和落地表现。
3. 选择电气场地，点新增的「预览电弧」，无需等待自动出现。
4. 可继续播放攻击/受击，检查是否保持巨大体型。

如果系统开启“减少动态效果”，电弧和雷光不会播放；预览状态栏会提示。请不要为了看效果强制改变自己需要的可访问性设置。

## 测量与边界

本地 1440 宽桌面预览中，喷火龙图片边界宽度为：普通约 320px、极巨约 493px（1.54 倍）、超极巨约 554px（1.73 倍）。这些是该视口的实际测量，不是所有设备固定倍率。

3 只预览宝可梦 × 桌面/手机宽度的巨大形态待机图片完整边界均留在战场内。体型仍会随可用空间自动适配。攻击会有短暂位移，测试不承诺所有物种、所有视口、每帧动作都完全不裁切。部分超极巨精灵资源沿用仓库的普通图回退机制，没有为所有物种重画精灵图。

npm test、18 组逐帧攻击/受击、普通极巨与超极巨各三回合实战回归通过；新增了尺寸比、待机边界、超极巨重播、手动电弧测试。真实酒馆与实体手机尚未复测。

## 安装

备份后，把完整网站包 pokemon-battle/ 内的内容覆盖到仓库根目录；保留自定义音频等附加素材。等待 Pages 部署完成，确认版本 v1.3.16。

导入配套角色卡，或将旧卡桥接加载地址改为 bridge.js?v=1.3.16。关闭旧战斗窗口，刷新酒馆及预览页。不能只换 CSS，本次涉及体型计算、位置适配、演出与环境脚本。
