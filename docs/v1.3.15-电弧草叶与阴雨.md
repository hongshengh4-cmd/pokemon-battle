# v1.3.15｜电弧、风吹草叶、阴雨雷光与沙尘滤镜

## 新增表现

- 电气：在连续铺展的地表上偶尔出现一小段跳跃电弧，事件之间保留较长间隔，不持续爆闪。
- 青草：移除所有地面草簇和草芽，保留连续地表底色；改成不同远近、大小、翻转角度的草叶随风掠过。
- 下雨：保持轻柔雨丝，新增灰蓝阴天滤镜和缓慢云影。首次雷光约在雨天开启 5.5 秒后，此后间隔约 9–16 秒；每次约 1.1 秒平缓出现并消退，不连续闪烁。
- 沙暴：保留轻柔沙粒，增加类似雪天整体滤镜的低饱和暖灰沙尘色调，不恢复浓密拖尾。
- 继续无背景图片，保留连续铺展、极巨化尺寸和稳定光晕修复。

雷电本次是**视觉效果，不含雷声**；不更改打雷招式命中率、伤害或天气逻辑。系统“减少动态效果”开启时，不播放电弧与雷光。

## 自由预览

当前会话打开「电弧、风吹草叶与阴雨预览 v1.3.15」。

- 选电气场地后观察数秒，电弧是偶发而不是一直出现。
- 选青草场地可看草叶随风翻转。
- 选下雨后可等待自动雷光，或点新增的「预览雷光」直接看一次。不是下雨时按钮禁用。
- 「重播蔓延」、体型切换和攻击/受击预览继续保留。

## 验证

自动化测试通过；测试了间歇电弧的出现和安静期、手动雷光及恢复、减少动态效果抑制、连续地表覆盖和蔓延。18 组攻击/受击逐帧尺寸与 25 种天气场地组合回归通过。未在你的真实酒馆会话或实体手机复测。美术观感请以实时预览为准。

## 安装

备份后将完整网站包内 pokemon-battle/ 的内容覆盖到仓库根目录，保留自定义音频等附加资源，等待 GitHub Pages 部署完成。

导入配套角色卡，或把现有卡的 bridge.js?v=旧版 改为 bridge.js?v=1.3.15。关闭旧战斗窗口并刷新酒馆，确认页面显示 v1.3.15。

部署后预览入口： https://hongshengh4-cmd.github.io/pokemon-battle/preview.html?v=1.3.15

远程仓库没有改动，要你部署后此线上地址才会更新。旧 docs 是历史说明，与本版本冲突的美术描述以本文件为准。
