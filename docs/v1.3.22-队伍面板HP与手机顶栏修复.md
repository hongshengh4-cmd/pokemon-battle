# v1.3.22 队伍面板 HP 与手机顶栏修复

针对移动端精灵球详情页修复两项问题：

1. **HP 与能力资料**：此前新伙伴在存档里使用 `hp: null`、`maxHp: null` 表示尚未受伤／满血，但详情面板把缺失的 `maxHp` 显示成 `—/—`，看起来像没有 HP。现在优先采用存档 `maxHp`；缺失时用本地种族值表、等级、个体值和性格计算展示上限。空 `hp` 按满血显示，明确 `hp: 0` 仍显示濒死，不会被覆盖；计算值只用于面板展示，不改写 MVU 里的满血标记。能力／个体资料默认展开。
2. **手机顶栏图标**：将队伍／仓库标签与定位、叫声、关闭按钮分组；操作按钮使用 18px 内嵌 SVG、固定 34px 尺寸并统一居中，消除 emoji 字体基线差异。窄屏时隐藏挤压标题，为控件组保留完整宽度。

角色卡作为独立 JSON 文件提供，不放在网站仓库 ZIP 中。卡内桥接 cache-buster：`st-bridge/bridge.js?v=1.3.22-panel-hp-icons-1`。

本版继续保留 v1.3.21 的同源 iframe 鼠标转向、游戏叫声 fallback 与长按打开面板修复。仓库根目录 `preview.html` 是战斗效果工作台，仍需保留；本包不包含酒馆互动演示页。
