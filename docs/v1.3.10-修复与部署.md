## 如何安装

1. 先备份你的仓库和酒馆聊天/角色卡。
2. 解压完整网站包，将其中 `pokemon-battle/` **里面的文件和目录**覆盖到仓库根目录。根目录应直接包含 `index.html`、`src/`、`st-bridge/`，不要额外套一层目录。保留自己添加的音频、图片等资产。
3. 提交并等待 GitHub Pages 部署完成。打开 https://hongshengh4-cmd.github.io/pokemon-battle/?v=1.3.10 ，确认页脚版本为 v1.3.10。
4. 在 SillyTavern 导入配套新角色卡（或手工把原卡脚本中的 `bridge.js?v=1.3.9` 改成 `bridge.js?v=1.3.10`，并更新对战协议）。已有聊天请先备份；不要依赖导入新卡自动迁移旧聊天。
5. 关闭正在进行的战斗窗口，刷新酒馆页面。如仍是旧版，清除该网站缓存后再刷新。新开一场战斗验证。

## 修复内容

### 极巨化攻击时恢复普通大小

- 原来的引擎先结算整个回合，包括回合末极巨化到期，再播放动画。视觉层会过早使用普通形态。
- 现在最后一回合攻击和受击播放期间保留回合前的极巨化/超极巨化精灵，特效结束后按实际尺寸比例缩回普通形态。
- 切换菜单、选择招式或刷新 HP 时，外观不变就复用精灵图片节点，减少 GIF 重载、动画重置造成的闪烁。
- 修正敌方精灵待机的负动画延迟影响有限攻击/受击动画的问题。

### 天气与场地表现

| 类型 | 表现 |
|---|---|
| 大晴天 | 暖色光照、柔和变化的阳光 |
| 雨天 | 冷色氛围、斜向雨丝 |
| 沙暴 | 沙色薄幕、横向沙粒 |
| 雪天 | 冷白氛围、飘落雪粒 |
| 电气场地 | 黄色地面光晕、闪动电弧 |
| 青草场地 | 绿色光晕、浮动叶片 |
| 薄雾场地 | 粉色地面雾带 |
| 精神场地 | 紫色光晕、漂浮能量环 |

天气与场地可叠加，结束后移除；不拦截按钮。只增加视觉反馈，不增加天气伤害或改变招式威力。原有文字、剩余回合仍保留。

天气别名 `sunnyday/raindance/sandstorm/hail/snowscape` 和中文名统一转换为引擎标识。桥接层支持同时传入天气和场地。配置为 0 回合时持续存在，正整数正常到期；补上了场地 0 回合的对应处理。

### 性能与可访问性

粒子数量固定，菜单重绘不重建效果层；手机减少可见粒子；系统开启“减少动态效果”时环境层改为静态。没有新增图片、视频或 CDN 依赖。

## 配置示例

角色卡 `<pkm_battle>` 内原来的 `"environment":"下雨"` 仍可用。天气和场地一起设置时：

```json
"environment": {
  "weather": "rain",
  "weatherTurns": 0,
  "terrain": "grassy",
  "terrainTurns": 5
}
```

天气：`sun/rain/sand/snow`；无特殊天气用 `clear` 或省略。场地：`electric/grassy/misty/psychic`；没有场地时省略。普通“晴朗”不一定是具有战斗加成的“大晴天”，按你的剧情需要设置。
