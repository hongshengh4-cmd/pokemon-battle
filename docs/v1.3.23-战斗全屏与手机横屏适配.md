# v1.3.23 · 战斗全屏与手机横屏适配

## 修复目标

角色卡启动的对战页以 `index.html?embed=1` 加载。旧样式仍受 `.panel` 最大宽度、内边距、固定战斗屏高度、圆角与投影影响；短屏横向手机还会触发仅按宽度设置的 700px 固定高度，造成裁切、空白或黑色边缘。战场顶部的 `#field-state` 也会多显示一条“战场：…”说明。

## 实现

- 嵌入模式的根页面、`main.panel` 与 `.battle-screen` 使用全视口定位和 `100dvh`；保留 `100vh` 回退。战斗场景／底部指令台无外边距、圆角或外投影，并移除 `.panel` 最大宽度限制。
- 实战 HUD 隐藏 `#field-state`，不影响天气或地形动画；效果预览工作台保留该读数。
- 短屏横屏断点 (`orientation: landscape`, `max-height: 560px`) 压缩指令台、记录和按钮；缩小精灵与状态框，减轻短屏重叠。使用安全区 inset 为刘海与圆角屏留操作空间。
- 竖屏窄屏采用记录在上、指令台在下的布局作为回退；主要操作仍按手机横屏优先优化。
- 角色卡所在的酒馆弹窗返回栏属于宿主页面，保留用于退出；下方 iframe 区域由战斗画面铺满。非嵌入的队伍编辑器、战斗效果工作台不改动。
- `index.html` 资源 cache-buster、桥接握手和 `st-bridge/kanto-data.js` 版本统一为 v1.3.23；配套角色卡仍单独分发，不放进仓库 ZIP。

## 验证

- `tests/battle-layout.test.mjs` 检查视口配置、嵌入全屏、隐藏说明条、横屏断点和竖屏回退。
- `npm test` 全套自动化回归。
- Playwright Chromium 在桌面横屏、手机横屏与手机竖屏测量战斗框是否贴合 iframe 视口、无外溢、说明条隐藏，并检查控制台异常。
- 仍需部署到 GitHub Pages 后通过 SillyTavern 实卡确认宿主设备上的最终效果；本地 iframe 测试不等同于用户实例验收。
