# v1.3.14｜自然铺展场地与轻柔天气

## 按这次反馈重做

- 场地是连续的全幅地表层，包含中间区域、左右边缘和敌方所在的远处，不再画成双方脚下两块贴片。
- 切换场地时约 1.8 秒由近处向远处逐渐铺开；没有向外扩散的圆圈。无背景图片。
- 青草：柔和地表材质、细小草簇、低幅度随风运动；不再用漂浮叶片代表草地。
- 薄雾：覆盖地面的低层雾带，缓慢流动，不在精灵脚下单独画雾团。
- 电气：低亮度、细密的地表流纹，不使用独立闪电符号和爆闪。
- 精神：柔和的地表折射流动，不使用光环、符号、晶体。
- 下雨/沙暴以下雪的轻柔感为参照：默认粒子数量分别约为雪天的 36% / 42%，降低速度、对比度和整体染色。雪天本身未调整。
- 保留之前的永久体型独立缩放与稳定极巨化红光。

## 先自由预览

会话中打开「自然铺展场地与轻柔天气 v1.3.14」。

可以选择天气和场地，点击新增的「重播蔓延」反复看场地铺开；仍支持攻击、受击、体型切换与天气粒子密度调整。不要只用静态截图判断运动观感。

美术风格是否符合你的预期，以你实际看预览为准；自动化测试不能判断审美。
