# v1.3.18 完整整合包 · 在线动图版

## 包含什么
- `pokemon-battle-v1.3.18-完整网站包.zip`：完整网站、外置桥接、数据、源码和自由效果预览。不包含本地宝可梦 GIF。
- `宝可梦·关都之旅-v1.3.18-在线动图与合并状态栏.json`：配套角色卡，包含此前从 v1.2.1 合并的状态栏。
- `超极巨动图在线检查.json`：本次对素材源的在线 HTTP 检查记录。

不需要再下载或叠加之前的版本包。本包不附带大截图、历史二进制素材或测试日志，以减少下载量。

## 安装顺序
1. 解压本外层整合包，再解压其中的完整网站包。
2. 将内层 `pokemon-battle` 文件夹里的内容部署到原网站仓库的网页根目录，保持 `src`、`st-bridge`、`index.html`、`preview.html` 等相对路径。不要把外层 ZIP 直接当作网站文件上传，也不要多嵌套一层 pokemon-battle 导致地址改变。
3. 如果仓库里已经上传过旧版 `src/ui/assets/sprites/`，请删除整个旧目录；仅覆盖上传新文件不会自动删除原来的 GIF。原本没有该目录则不需要处理。
4. 等待网站部署完成，确认网页页脚为 v1.3.18。若仍显示旧版本，强制刷新或清理该站点缓存。
5. 导入本包的角色卡。在酒馆助手中开启 MVU 加载、`关都之旅·外置桥接 v1.3.18`、`关都之旅·状态栏（v1.2.1 合并）`，然后刷新页面。无需另装旧版卡或旧版精灵球脚本。
6. 打开同站点的 `preview.html`，可不进入正式战斗，自由预览天气、场地、巨大形态与电弧。

角色卡继续引用原站点 `https://hongshengh4-cmd.github.io/pokemon-battle/`，桥接与网页缓存版本更新为 v1.3.18。本次只提供文件，没有修改线上仓库或远程部署。

## 这次改了什么
- 删除之前打包的全部 14 个本地 GIF。
- 删除自由预览专用的本地 GIF 覆盖逻辑；正式对战与预览统一使用 HTTPS 在线精灵映射和既有失败回退链。

- 保留 v1.3.17 的天气场地、电弧、明显巨大化、动态尺寸适配和扩大阴影，以及合并后的状态栏。
- 修正颤弦蝾螈低调形态的超极巨素材映射，复用相同超极巨外形；千面避役缺少背面超极巨 GIF 时改用已存在的正面超极巨动图镜像，而非优先使用普通形态背面。

## 在线素材的实际覆盖范围
在线加载不代表上游一定具备每一种动图。本次核查本地数据中的 34 个超极巨形态条目、每条正背两个方向，共 68 个独立形态动图 URL，其中 55 个返回 HTTP 200。

检查时以下 6 个形态的独立正背动图 URL 返回 404：
- 超极巨化妙蛙花
- 超极巨化水箭龟
- 超极巨化轰擂金刚猩
- 超极巨化闪焰王牌
- 超极巨化武道熊师（一击流）
- 超极巨化武道熊师（连击流）

这些条目沿用现有普通形态素材回退，仍显示巨大化效果，但不能算拥有独立超极巨外形动图。千面避役另有背面缺失，已按前述方式用正面超极巨动图镜像兜底。未生成或冒充缺失素材。在线可用性可能随上游调整而变化；网络不通时也可能触发其他原有降级或占位图。
