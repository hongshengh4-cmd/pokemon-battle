# 配套完整角色卡

- `宝可梦·关都之旅-v1.3.20-完整配套角色卡.json`：可直接导入的 Tavern Card V3 完整角色卡。包含原有设定、世界书、开局流程、状态栏、MVU/酒馆助手脚本，以及卡侧旧版情绪互动插件。
- `酒馆交互预览.html`：酒馆风格的本地互动演示，不连接或修改你的酒馆存档。

## 配套关系

角色卡脚本默认从 `https://hongshengh4-cmd.github.io/pokemon-battle/` 加载本仓库的 v1.3.20 桥接。请先部署仓库，再导入卡；如使用其他 Pages 地址，修改卡内脚本 `scripts[1]` 的 `PKM_APP_BASE_URL`。

导入和启用步骤见 [`../sillytavern/README.md`](../sillytavern/README.md)。
