# v1.3.13｜天气可见度、双方场地、稳定红光

## 本次修改

1. 雨天：提高粒子数量与雨丝长度，用深色描边和浅色内芯增强在原浅色底板上的对比；增强涟漪。
2. 沙暴：加深沙粒、增加方向性短拖尾，增强沙尘带；仍可用预览中的粒子密度滑块调整数量。
3. 四种场地：不再固定画在画面下半部，分别读取我方、敌方精灵框的实际地面位置和阴影横坐标，按近大远小绘制。效果边界渐隐，窗口改变尺寸时重新定位。
4. 极巨化红光：移除持续的红色 GIF 轮廓 drop-shadow，改为精灵背后的独立径向光晕。光晕恒定透明度、不播放动画、不以 GIF 每帧的透明轮廓生成。不会关闭攻击、受击或变身本来就有的瞬时效果。
5. 保持无背景图片、保留极巨化尺寸修复与自由预览。

## 测试范围

- npm test 全部通过。
- 四种场地 × 桌面/手机两种宽度：读取双方脚下 Canvas 像素，双方都有可见效果。
- 喷火龙持续光晕 35 次采样：独立层透明度和背景不变，无动画、无滤镜；精灵本身不再有持续红色轮廓滤镜。
- 18 组攻击/受击的逐帧尺寸回归、25 种天气场地预览组合通过。
- 普通极巨化、超极巨化各连续三回合实战回归通过。

这些验证不能证明所有手机/GPU 上绝无闪烁。用户截图为静态图，无法由它确认闪动根因。本次针对 GIF 轮廓滤镜随透明帧变化的风险进行结构调整。请优先在你的设备上试实时预览；如果仍闪，请发 3–5 秒录屏并注明是否在待机或攻击期间、浏览器与版本。

## 安装

备份旧网站和聊天后，将完整网站包内 pokemon-battle/ 里面的内容覆盖到仓库根目录，等待 GitHub Pages 部署完成。保留自定义音频、图片等附加资源。

导入配套 v1.3.13 角色卡；或把原卡的 bridge.js?v=旧版本 改为 bridge.js?v=1.3.13。关闭旧战斗窗口，刷新酒馆和预览页。确认页面显示 v1.3.13。

请一起更新 src/ui/app.js、styles.css、field-fx.js、入口 HTML 和桥接版本，不要只换其中一个文件。若缓存未刷新，请强制刷新页面。
