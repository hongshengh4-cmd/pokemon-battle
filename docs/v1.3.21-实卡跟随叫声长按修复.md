# v1.3.21 实卡跟随／叫声／长按修复

本次针对酒馆实卡而非独立预览页修复三项行为：

1. **鼠标转向**：主页面与同源消息 iframe 都监听鼠标移动，并把 iframe 内坐标换算到主页面。
2. **叫声**：当前网站包没有动漫 MP3；没录音时默认同步播放 Pokémon Showdown 原作游戏叫声，避免第一次点击等 404 后才回退、被浏览器拦截。语音合成仍可在面板手动选择；游戏叫声不是动画配音。
3. **长按队伍／仓库面板**：跟随伙伴按住 520ms 后直接调用桥接公开的 `openPanel()`；不再依赖隐藏精灵球按钮的合成点击。短按互动和拖动保持分离。

角色卡加载地址：`st-bridge/bridge.js?v=1.3.21-follow-voice-hold-1`。
