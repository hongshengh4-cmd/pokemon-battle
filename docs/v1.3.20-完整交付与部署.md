# v1.3.20 完整交付与部署

## 交付物

- 完整 GitHub Pages 静态仓库：仓库根目录及 `src/`、`st-bridge/`、`tests/`、`tools/` 等。
- 配套 Tavern Card V3 角色卡：`character-card/宝可梦·关都之旅-v1.3.20-完整配套角色卡.json`。
- 酒馆式本地互动预览：`character-card/酒馆交互预览.html`。

ZIP 中不含 `.git` 历史和 `node_modules`；所有运行所需站点代码、图片、数据、桥接文件和测试源码都已包含。网页是静态结构，无需 `npm run build`。

## 部署检查表

1. 解压仓库 ZIP。
2. 把外层目录里的文件**直接**放到 GitHub Pages 仓库根目录，保留 `index.html`、`src/`、`st-bridge/` 的相对结构。
3. 启用 Pages 并等待发布。
4. 打开主页，检查页脚 `v1.3.20`。
5. 打开 `https://hongshengh4-cmd.github.io/pokemon-battle/st-bridge/bridge.js?v=1.3.20`，确认不是 404。
6. 最后将完整角色卡 JSON 导入 SillyTavern，启用 MVU 与 JS-Slash-Runner/酒馆助手，并允许脚本执行。

若使用其它仓库地址，需修改角色卡 `scripts[1]` 的 `PKM_APP_BASE_URL`。预览 HTML 是本地模拟数据，不会写入 MVU。

## v1.3.20 包含的关键修正

- 状态栏只列出 `met=true` 的已结识人物；手机窄屏地点/时间允许完整换行。
- 跟随中的宝可梦替代浮球；拖动、普通短按叫声/互动和长按队伍面板独立处理。
- 卡侧旧情绪互动插件读取 `PKMKanto.read()`：HP、异常状态、四项羁绊和值、表情/粒子、游走/凝视、抚摸、睡眠/唤醒和消息事件。
- 对战回归：守住连用成功率递减；火系免灼伤、冰系免冰冻、绝对零度不能击倒冰系；毒菱仅接地毒系吸收；飞行/飘浮免疫撒菱、黏黏网与接地场地效果，但仍受隐形岩伤害。
