# v1.3.17｜分叉放电与巨大形态阴影

## 本次修改

### 电气场地

取消上一版几段简单折线的表达，改为分层局部放电：沿通道逐段推进、主通道加三条次级分叉、较白的细亮芯和多层暖色柔光、末端短暂地面光溢出。电流形状随时间小幅爬动，亮度包络平滑消退，不做整屏频闪。

仍然有安静期，不一直放电。自由预览选电气场地，点击「预览电弧」可直接观察。本次是程序绘制的风格化放电，美术质感请以动态预览为准，不以测试通过代替你的判断。

### 巨大形态阴影

旧代码将影子宽度上限设为精灵框的92%，高度上限固定30px；精灵变大时影子很快达到这个普通体型上限。

现在巨大形态依据实际图片尺寸、实际永久缩放计算投影，允许超过普通精灵框。阴影分为较宽较柔的整体投影与更小更暗的脚底接触暗部，两层共享校正后的地面锚点。普通形态仍保留原有范围，避免小宝可梦影子变得过大。

本地桌面喷火龙实测：普通影子约243×27px，极巨化约404×69px，超极巨化约454×77px；会随视口、图片素材、最终适配尺寸改变，不是写死的固定大小。

## 预览与测试

会话中打开「分叉放电与巨大形态阴影 v1.3.17」。切换普通/极巨化/超极巨化比较身体与影子，再选电气场地点「预览电弧」。

npm test 通过；三只预览宝可梦×桌面/手机宽度的影子增大、分层、地面位置检查通过；18组巨大形态攻击/受击逐帧尺寸回归与25种天气场地组合检查通过。真实酒馆、实体手机尚未复测。系统“减少动态效果”会关闭电弧动态。

继续保持无背景图片，保留草叶、阴雨雷光、沙尘滤镜、连续地表和巨大化修复。

## 安装

备份后将完整网站包 pokemon-battle/ 内的内容覆盖到原仓库根目录，保留自己的音频等附加资源。等待 Pages 部署完成。

导入配套角色卡，或把旧卡桥接脚本地址改成 bridge.js?v=1.3.17。关闭旧对战窗口并刷新酒馆、预览页，确认 v1.3.17。请一起更新体型计算、CSS、app与环境脚本，不要只替换一份文件。

部署后预览： https://hongshengh4-cmd.github.io/pokemon-battle/preview.html?v=1.3.17

远程仓库没有修改或推送，线上地址需你部署后才更新。旧docs为历史说明。
